# ADWAITH K. — Digital Universe

Premium interactive portfolio starter built with React, TypeScript, Vite, Three.js / React Three Fiber, Framer Motion and Lucide.

## Run in VS Code

1. Extract `adwaith-digital-universe.zip`.
2. Open the extracted `adwaith-digital-universe` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:

```powershell
npm install
npm run dev
```

5. Open the localhost URL shown by Vite, normally `http://localhost:5173`.

## Build for production

```powershell
npm run build
npm run preview
```

## Main files

- `src/main.tsx` — application and sections
- `src/styles.css` — premium visual system and responsive layout
- `src/data/resume.ts` — resume source content
- `vite.config.ts` — Vite configuration

The project intentionally uses only information supplied in the resume and does not invent certifications, employers, project results, or skill levels.
